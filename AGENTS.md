# Project agent entry point

Read `Codex Md Files/Meta.md` at the start of work in this repository. Follow its two-minute progress-update rule during active work. Use `Codex Md Files/PROJECT_CONTEXT.md` for current scope, status, and next steps. Load papers and source code selectively for the current task; do not preload them all.

Do not read or preload `project-logs/` during routine work. Read a specific log only if the user asks for it or a needed historical detail is unavailable from `Codex Md Files/PROJECT_CONTEXT.md` and the saved experiment records.

Do not launch or resume any command that makes paid model API calls unless the user explicitly asks the agent to execute the run. A request to prepare settings, fix resume behavior, audit outputs, or discuss finishing a run is not authorization to start it. Offline tests and read-only inspection are fine.
